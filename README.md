## 專案研究摘要

本專案為 Python 科學計算堆疊（NumPy 與 Matplotlib）於土木工程科學領域之技術研究成果作品集。包含結構動力學阻尼餘弦震盪、二維圓柱位勢繞流流場、水利水位歷時量測以及年度氣候週期諧波模擬。

專案包含：
1. **GitHub Wiki**：7 份模組化技術章節與研究札記（位於 `wiki/` 目錄）。
2. **圖表資源庫**：10 張真實作業萃取之工程圖表（位於 `assets/` 目錄）。
3. **自動化工具**：純標準函式庫編寫之 HTML 建置與離線合規性掃描腳本（位於 `tools/` 目錄）。
4. **離線作品集 HTML**：完全獨立、零 CDN 依賴之高質感互動式研究成果報告（位於 `output/` 目錄）。
