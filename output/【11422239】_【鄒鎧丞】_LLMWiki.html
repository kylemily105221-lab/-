01 分段函數與阻尼衰減波形 (Damped Oscillations)
結構動力學基礎

研究目的與問題背景

土木結構物（如大跨徑懸索橋、超高層大樓）在遭遇地震或陣風擾動後，振動能量藉由材料內摩擦與阻尼裝置耗散。本單元探討 Python 條件邏輯與連續函數取樣，模擬不同阻尼係數下的位移衰減歷時曲線。

核心數學模型與公式推導
f(x) = \begin{cases cos(x), & x < 0 \\ e^{-x, & x ≥ 0 \end{cases
y(x) = e^{-α x cos(x),   y_{envelope(x) = ± e^{-α x
Python 原始碼 (RAW/W03/main.ipynb Cell 1) 
def func(x):
    if x < 0:
        return np.cos(x)
    return np.exp(-x)

print(func(-3))
print(func(8))
# 實際執行結果:
# func(-3) = -0.9899924966004454
# func(8)  = 0.00033546262790251185

展示兩條不同指數包絡衰減曲線 y = exp(-αx)cos(x)，取樣範圍 x ∈ [0, 10π]（約 5 個振動週期）。

工程意義
對應線性單自由度（SDOF）低阻尼系統的自由振動位移包絡線衰減特徵。

import numpy as np
import matplotlib.pyplot as plt

def func(x, a):
    return np.exp(-a * x) * np.cos(x)

x = np.linspace(0, 10 * np.pi, 1000)

for a in [0.1, 0.2]:
    plt.plot(x, func(x, a), label=f"a={a}")
plt.xlabel("x")
plt.ylabel("exp(-ax)cos(x)")
plt.legend()
plt.grid(True)
plt.show()

02 自訂函數、極座標幾何與圓柱繞流 (Functions & Polar)
流體力學與幾何轉換

研究目的與問題背景

土木水利工程常面臨圓形結構（橋墩、水下圓柱管道）受流體沖刷的問題。在直角座標系下邊界條件複雜，透過極座標變換（r, θ）可將邊界大幅簡化。本單元探討全象限逆正切、距離運算與二維圓柱流線函數之實作。

核心數學模型與推導
r = √(x² + y²),   θ = atan2(y, x)
ψ(r, θ) = \begin{cases 0.0, & r ≤ R \\ U ≤ ft( r - R²r \right) sinθ, & r > R \end{cases
Python 原始碼 (RAW/W03/main.ipynb Cell 4-13 節錄) 
# 象限與幾何距離運算
x, y = -2, 2
theta = np.arctan2(y, x)
print(theta / np.pi)  # 輸出: 0.75 (第二象限角 3π/4)

r = np.hypot(0.5, 0)
R = 1.5
print(r <= R)  # 輸出: True (落於柱內)

# 二維圓柱流線函數
def psi(x, y, U=1, R=1):
    r = np.hypot(x, y)
    if r <= R:
        return 0.0
    theta = np.arctan2(y, x)
    return U * (r - R**2 / r) * np.sin(theta)

print(psi(2, 4, U=2, R=1.5))    # 輸出: 7.1000000000000005
print(psi(0.5, 0, U=2, R=1.5))  # 輸出: 0.0 (柱內流線屏蔽)

數值驗證與理論對照

點 (2, 4) 於參數 U = 2, R = 1.5 下之理論解推導：

r = \sqrt{2² + 4² = √20,   sinθ = \frac{4{√20
ψ = 2 × ≤ ft( √20 - \frac{2.25{√20 \right) × \frac{4{√20 = 2 × 17.7520 × 4 = 7.1

理論推導值 7.1 與程式實際執行結果 7.1000000000000005 完全吻合（小數末位浮點誤差為 IEEE 754 雙精度標準特徵）。

05 土木工程計算應用統整 (Engineering Summary)
跨領域整合

土木工程計算架構與核心技術連結

本週程式分析不僅止於 Python 語法，更緊密連結土木結構、水利水文與環境材料的三大核心面向：

結構動力學 (Structural Dynamics)
指數阻尼餘弦模型 y = exp(-αx)cos(x) 完美對應單自由度結構受到衝擊後之自由衰減響應。阻尼比增大（α: 0.1 → 0.2）能使結構於 5 個週期內完全耗散動能，防止共振破壞。
水利與流體工程 (Hydraulic Engineering)
二維位勢流流線函數 ψ(r, θ) 直觀模擬了水流繞過圓形橋墩時之流場。橋墩兩側側面流速倍增至 2U，引發局部劇烈壓降，是水利沖刷與基樁淘空防護的核心力學根源。
環境載重與熱應力 (Thermal Engineering)
諧波氣溫模型揭示了極端大陸性氣候與海洋性氣候在結構伸縮縫選型上的差異。大體積混凝土澆置時亦需監測內外溫差，避免收縮拉應力超過抗拉強度導致貫穿裂縫。
